Statistik Augsburg interaktiv

Hier lesen Sie in Leichter Sprache: Was ist diese Internet-Seite? Und wie können Sie die Seite bedienen?

Was ist diese Internet-Seite?

Diese Internet-Seite ist von der Stadt Augsburg.

Auf der Seite finden Sie Zahlen über die Menschen in Augsburg.

Zum Beispiel:

  • Wie viele Menschen wohnen in Augsburg?
  • Wie alt sind die Menschen?
  • Wie viele Menschen haben Arbeit?
  • Wie viele Menschen wohnen allein?

Die Zahlen sind von 1999 bis heute.

Sie können die Zahlen für ganz Augsburg sehen.

Sie können die Zahlen auch für einen Stadt-Teil sehen.

Was ist ein Stadt-Bezirk?

Augsburg ist in Teile aufgeteilt.

Diese Teile heißen Stadt-Bezirke.

Augsburg hat 42 Stadt-Bezirke.

Ein Stadt-Bezirk ist zum Beispiel Kriegshaber.

Ein anderer Stadt-Bezirk ist Lechhausen.

So bedienen Sie die Seite

Oben auf der Seite sind Knöpfe.

Sie klicken auf einen Knopf.

Dann ändern sich die Zahlen.

Die Knöpfe bei Ansicht

  • Detail-Ansicht: Sie sehen die Zahlen von einem Jahr.
  • Zeit-Reihe: Sie sehen die Zahlen von vielen Jahren.
  • Innerstädtischer Vergleich: Sie sehen alle Stadt-Bezirke auf einer Karte.

Die Knöpfe bei Jahr

Sie klicken auf ein Jahr.

Dann sehen Sie die Zahlen von diesem Jahr.

Die Knöpfe bei Themen-Bereich

Sie klicken auf ein Thema.

Zum Beispiel auf Haushalte.

Dann sehen Sie die Zahlen zu diesem Thema.

Die Karte

Rechts sehen Sie eine Karte von Augsburg.

Sie klicken auf einen Stadt-Bezirk auf der Karte.

Dann sehen Sie die Zahlen von diesem Stadt-Bezirk.

Sie können auch links auf einen Namen klicken.

Das geht auch mit der Tastatur.

Ihre Adresse suchen

Sie wissen nicht: In welchem Stadt-Bezirk wohne ich?

Dann schreiben Sie Ihre Straße in das Feld Straße.

Dann schreiben Sie Ihre Haus-Nummer in das Feld Hausnummer.

Die Seite zeigt Ihnen dann Ihren Stadt-Bezirk.

Die Seite größer machen

Oben rechts ist der Knopf Darstellung.

Sie klicken auf den Knopf.

Dann können Sie das einstellen:

  • Schrift-Größe: Die Schrift wird größer.
  • Kontrast: Die Farben werden kräftiger. Dann können Sie besser lesen.
  • Karten: Die Karte bekommt Muster. Dann sehen Sie die Unterschiede auch ohne Farben.

Der Computer merkt sich Ihre Einstellung.

Sie finden einen Fehler?

Vielleicht können Sie etwas nicht lesen.

Oder ein Knopf funktioniert nicht.

Dann schreiben Sie uns.

Wir helfen Ihnen.
